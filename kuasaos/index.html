☁️ Sambungan Pangkalan Data Percuma Google Sheets

Simpan semua rekod ARA, HIRA, SAFA, POS, Inventori & Katering terus ke Google Sheets anda secara percuma.

Status: Sedia untuk disambungkan (atau muat turun JSON/CSV di bawah).

Langkah 2: Skrip Google Apps Script Percuma (Salin ke Extensions → Apps Script dalam Google Sheet) 
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var payload = JSON.parse(e.postData.contents);
  var tables = ['leads', 'staff', 'ledger', 'inventory', 'bookings', 'contentCalendar'];
  tables.forEach(function(name) {
    var sheet = ss.getSheetByName(name) || ss.insertSheet(name);
    sheet.clearContents();
    var rows = payload[name] || [];
    if (rows.length > 0) {
      var headers = Object.keys(rows[0]);
      sheet.appendRow(headers);
      rows.forEach(function(r) {
        sheet.appendRow(headers.map(function(h) { return r[h]; }));
      });
    }
  });
  return ContentService.createTextOutput(JSON.stringify({ status: 'ok', syncedAt: new Date() }))
    .setMimeType(ContentService.MimeType.JSON);
}
